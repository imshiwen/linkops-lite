## 3. 实验(我写好了脚本,你跑并写结论)

先挑 5 个入口:2 个 AI 工具目录、1 个通用软件目录、1 个免费工具目录、1 个你认为适合的。然后:

```bash
python3 eval/day02_experiment.py --ids 4,9,40,<id>,<id> --runs 3
```

脚本会对比 5 组配置:基线、temperature=0、temperature=1.2、开启思考、原生 json_schema。

实际运行:2026-10-17,入口 id 4、6、9、136、46,每组每个入口 3 次,共 75 次调用。
原始结果:`eval/results/day02-20261017-1951.md`;人工标注:`eval/labels.csv`。

| 配置 | 稳定性(3 次结论相同) | 与人工标注一致 | 失败 | 平均耗时 | 输入 / 输出 token |
|---|---:|---:|---:|---:|---:|
| 基线:不思考,默认温度 | 3/5 | 12/15 | 0 | 5.9 秒 | 2329 / 324 |
| **不思考,temperature=0** | **5/5** | **15/15** | 0 | **4.7 秒** | 1921 / 277 |
| 不思考,temperature=1.2 | 2/5 | 9/15 | 0 | 5.6 秒 | 2433 / 313 |
| 开启思考 | 4/5 | 6/15 | 1 | 56.7 秒 | 2050 / 2090 |
| 不思考,原生 json_schema | 3/5 | 8/15 | 0 | 7.8 秒 | 1391 / 347 |

**结论:研判默认用"关闭思考 + temperature=0"。** 结构化输出方式暂时保持提示词约束,等标注样本变多后再比较原生 json_schema。

### 从实验里看到的 5 件事

1. **temperature=0 最适合研判。** 最稳定、最准、最快、最省。研判是标准明确的分类任务,要的是一致,不是创意。
2. **temperature 调高会让结论漂移。** 1.2 时,同一个站三次能给出两种结论,稳定性只有 2/5。
3. **开启思考在这个任务上不划算。** 慢 10 倍、输出 token 多 7 倍,准确率反而最低:它倾向于给出"不确定",还失败了 1 次。思考适合多步推理,不适合标准明确的分类。
4. **原生 json_schema 能省输入 token。** 输入从 2329 降到 1391,少 40%,因为 schema 不再写进提示词。这验证了"输入 token 变多是因为 schema 变长"的推测。但这次准确率偏低,样本太少,暂不切换。
5. **模型和人工不一致时,错的不一定是模型。** SaaSHub 我最初标"不适合",模型三次都判"适合"。复核后发现是我的标准太窄:它是通用软件目录,不只收 AI 工具。改标后 temperature=0 全对。由此定下"宽进"原则(见 `design.md`):先复核标注标准,再决定改 prompt 还是改标注。

### 实验的局限

- 只有 5 个站、各 3 次,结论是方向性的,后续用更多标注样本验证。
- 同样的 prompt 在不同配置下输入 token 不同,可能来自重试累计或每次抓取的页面差异,结果表没有记录重试次数,下次实验要补上。

### 面试怎么讲:研判任务怎么选模型参数?

> 我用 5 个人工标注的站对比了 5 组配置,每组跑 3 次。关闭思考 + temperature=0 最好:15 次全对、三次结论一致,也最快最省。
> temperature 调到 1.2 后,同一个站三次能给出两种结论;研判是分类任务,要一致而不是创意。
> 开启思考反而最差:慢 10 倍、输出 token 多 7 倍,还倾向给"不确定"。思考适合多步推理,不适合标准明确的分类。
> 原生 json_schema 能让输入 token 降 40%,但这次准确率偏低,样本太少,先不切换。
> 还有一点:模型和我的标注不一致时,我复核发现是我的标准太窄,于是把筛选定为召回优先,后面靠人工审核兜底。

## 4. 已知事实(我验证过的)

- qwen3.8-flash **默认开启思考**:只回复"你好"时 26 个输出 token 里有 22 个是思考 token。脚手架默认传 `enable_thinking=false`。
- 用占位 prompt 研判 SaaSHub:输入 1256 token,输出 203 token,耗时 6.3 秒,结论"不适合"(B2B 软件目录,与花体字工具受众不符)。
- 百炼文档:思考模式下 temperature 低于 0.6 会被改成 0.6;`json_object` 要求提示词里出现 JSON 字样。
