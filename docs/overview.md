# 总览:十天 AI 工程能力 × linkops-lite

> 回顾入口。只放方向、进度、决策和文件位置;细节点进各文件看。
> 最后更新:2026-10-18

## 1. 目标

10 天内掌握 AI 工程师最短路线的 10 组能力(来源 roadmap.sh/ai-engineer),面向 Java 岗位面试。
练习方式 **A**:每组能力都在 linkops-lite(外链工作台)里做一个用得上的功能。
硬规则:十天内只做路线上的事;浏览器扩展、页面美化等排到十天之后(记到 `ideas.md`)。

## 2. 协作方式

| 角色 | 做什么 |
|---|---|
| 主会话 | 方向调整、发现不一致、学习卡需要修改;维护本总览 |
| 侧边会话 | 某一天的内容需要深入理解时单独开,学完不改方向 |
| 分工 C | 框架和样板代码由 Claude 写;**每天的核心 AI 代码由你写**(prompt、结构化输出、校验、分批、评估指标) |

侧边会话改了代码或文档时,在主会话说一声,由主会话核对是否和方向一致。

## 4. 已定的关键决策

| 日期 | 决策 | 理由 / 出处 |
|---|---|---|
| 10-16 | 新开轻量项目,不在旧 LinkOps 上改 | 旧项目太重;`design.md` |
| 10-16 | Java 21 + Spring Boot 4 + MyBatis + Flyway + Neon(dev 分支)+ pgvector | 面向 Java 岗;`architecture.md` |
| 10-16 | 外链列表全局入库一次;入库只做便宜初筛,选用时才调模型研判 | 控制成本;`design.md` |
| 10-16 | 可访问性检查只把 404/410、证书失效判失效,网络类失败记 unreachable | 本机经代理,结果受环境影响;`day-01.md` |
| 10-16 | 批量准备 + 填表自动,提交由人点 | 不绕验证码,避免垃圾外链;`design.md` |
| 10-17 | 对话 qwen3.8-flash、Embedding qwen3.7-text-embedding(1024 维),均为百炼,配置各自独立 | 方便以后分别换模型 |
| 10-17 | 代码按层存放:controller / service(只编排)/ component(功能类)/ mapper / dto / entity / util | `architecture.md` |
| 10-18 | 研判默认关闭思考 + temperature=0 | 实验 15/15 全对且最快;`day-02.md` |
| 10-18 | 研判"宽进",召回优先,用等级区分优先级 | 外链尽量多发,人工审核兜底;`design.md` |
