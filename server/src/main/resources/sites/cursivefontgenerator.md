# Cursive Font Generator

- 域名:cursivefontgenerator.online
- 一句话:免费的 Unicode 花体/艺术字转换工具,输入文字即可预览并复制多种字体样式。
- 类型:在线文字工具(不是 AI 产品,不需要注册,不收费)。
- 主要功能:
  - 首页提供 20 种字母样式(cursive、bold、decorative 等),即时预览,一键复制。
  - 14 个工具页:按风格(粗体、删除线、倒置等)和平台(Instagram 简介与配文等)区分。
  - 支持多行输入,复制时保留换行。
- 典型用途:社交媒体简介、配文、昵称、消息里的装饰文字。
- 语言:英文站。
- 目标用户:需要在 Instagram 等平台使用花体字的普通用户。
